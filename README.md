# 0 - bminde-video-production

مهارة لإنتاج فيديوهات عربية لقناة بمايند، مع تعليق وثائقي واضح، وتشكيل يراعي المعنى والسياق، ومراجعة المصادر العلمية والتزامن والملفات النهائية.

## التثبيت

انسخ محتويات هذا المستودع إلى مجلد `bminde-video-production` داخل مجلد المهارات الذي يستخدمه وكيلك. الاسم المعروض هو `0 - bminde-video-production`، ومعرّف الاستدعاء هو `$bminde-video-production`. اقرأ `SKILL.md` بعد التثبيت واتبع `references/portability.md`. يمكن لأي وكيل قراءة الملف مباشرة؛ اكتشاف المهارات تلقائيًا يعتمد على البرنامج المضيف.

## توليد التعليق الصوتي

يتطلب المساعد الاختياري Python 3.10 أو أحدث:

```sh
python -m venv .venv
# Activate the environment using your shell, then:
python -m pip install -r requirements.txt
python scripts/synthesize.py --input script.txt --voice ar-SA-HamedNeural --output episode.mp3 --rate=-5%
```

تستخدم الأداة خدمة Microsoft عبر الإنترنت وترسل إليها النص. لا تُضمّن مفاتيح API أو بيانات دخول. إصدار edge-tts مثبت هنا لإعادة إنتاج البيئة المختبرة، ولا يضمن استمرار توافر الخدمة. راجع شروط الخدمة قبل الاستخدام المقصود. يلزم FFmpeg/ffprobe لفحص التسجيلات والوسائط؛ ولا يلزمان لمجرد قراءة التعليمات.

## ما تتضمنه النسخة

- تشكيل العربية وفق معنى الجملة، واتفاق التذكير والتأنيث والتنوين.
- عينة حامد مرجعية ونصوص أمثلة؛ كل تسجيل جديد يحتاج إلى مراجعة مستقلة.
- توثيق الادعاءات العلمية وحدود الدراسات، وتمييز الأمثلة المؤلفة.
- إرشادات تركيب المشاهد والتحقق من مدة الفيديو وسلامته.

هذه حزمة المهارة والتعليمات وليست مشروع Remotion أو حلقات مكتملة. لا تمنح إعداداتها إذنًا بالنشر على أي قناة.

## الخصوصية

حُذفت اقتباسات المحادثة ومعرّفات القناة وروابطها من نسخة النشر. لا تتضمن هذه النسخة سجلات محلية أو مسارات جهاز أو أسرار اتصال. احتُفظ باسم بمايند لأنه هوية المهارة المطلوبة. نُزعت بيانات الوسم من العينة الصوتية.
