# Security Policy

## Supported versions

Only the latest version on the `main` branch receives security fixes.

## Reporting a vulnerability

Please do not open a public issue or pull request for a security problem.

Report it privately to the repository owner at bahattab@gmail.com, with the subject line "SECURITY: [short title]".

Include:

- A description of the vulnerability and its impact.
- Steps to reproduce, or a proof of concept.
- The affected file, version, or commit, if known.
- A suggested fix, if you have one.

You can expect an acknowledgement within 7 days. Confirmed issues are fixed as soon as practical, and you will be credited if you wish.

## Secrets

Do not commit passwords, API keys, tokens, or `.env` files. If you find one in the repository, report it using the steps above so it can be revoked and removed.
